workbuddy2everything

github.com/kangjiazhen/workbuddy2everything
一个本地反向代理，同时接管 Codex 与 Claude Code。
不装插件、不改二进制。把 Responses API 与 Anthropic Messages 两种方言翻译成同一个上游， system 层、账号矩阵、权限档位全部在你自己的机器上。
01

破甲

System-layer injection
  • 把客户端自带 system 整段替换成你的指令，三种拼装：replace / append / prepend
  • Claude Code 的 base prompt 是成体系的反注入规程，实测只有 replace 能过；代价是身份丢失，用尾注锁名字
  • 单层原则：同一指令出现两次即自证注入，所以不再写 AGENTS.md / CLAUDE.md
02

账号矩阵

Account pool
  • 网关侧账号池统一调度：max_in_flight 限流、会话粘性、失败换号，客户端无感
  • 出站指纹脱敏，请求头与版本号按账号归位，不串味
  • 一个 key 对外，背后是整排账号；加号、停号只动网关配置
03

免费积分

Free credits
  • 走账号自带的免费额度，不必给每个客户端单独充值、单独买 key
  • 额度耗尽/限流自动转到下一个可用账号，不中断对话
  • 本地 127.0.0.1 直连，不经过任何第三方中继
04

反向代理

Reverse proxy · two dialects
  • :7888 同时说 Responses（Codex）与 Anthropic Messages（Claude Code / Claude Desktop）
  • SSE 全事件序列自实现：response.failed / error 带真实原因，不再伪装成断流
  • /v1/models 透传网关真实目录，选哪个模型就走哪个
